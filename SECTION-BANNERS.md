# Баннеры разделов · 5.6.0

20 изображений сгенерированы в едином стиле аватарки SBAND ACCS: тёмный фон,
лаймовые объёмные символы, тонкое кольцо и одинаковая типографика.

В Telegram баннер появляется в сообщении **над кнопками** соответствующего
раздела. Telegram не поддерживает произвольные картинки внутри inline-кнопок.
Оформлены главное меню, каталог, профиль, кошелёк, покупки, обращения, бонусы,
промокоды, реферальная система, информация, отзывы и поступления. Админка
использует собственные баннеры панели, склада/категорий, пользователей,
статистики, настроек, рассылки, контроля/проверок и тестового магазина.
Вложенные действия используют оформление своего раздела.

Изображения: `assets/banners/*.png`; главное меню: `assets/welcome.png`.
Фото главного меню по-прежнему можно менять через существующий редактор
кнопок в админке. Изменение файла автоматически сбрасывает его кэш.
Пути абсолютные относительно проекта: запуск из другой рабочей папки
не мешает найти баннеры.

Общий помощник `utils/nav.py` обновляет фото, подпись и клавиатуру одним
редактированием сообщения. Внутри одного раздела меняются подпись и кнопки.
Telegram file_id кэшируется отдельно для каждого бота/раздела в процессе;
повторный переход использует уже загруженную картинку. После перезапуска
первое открытие раздела загрузит файл заново. Если Telegram запрещает
редактирование старого сообщения, новое отправляется **до** удаления старого.

Лимит подписи Telegram — 1024 символа после разбора HTML. Если описание,
список пользователей или переписка больше лимита, показывается полный текст
без баннера, без обрезки данных. При возврате в короткий раздел баннер
появляется снова. Если файл отсутствует, доступен обычный текстовый экран.

Меняются только явно определённые экраны навигации. Чеки Stars, платёжные
обновления, вложения обращений и содержимое рассылок не перехватываются
глобальным оформлением. Коды входа и реквизиты остаются копируемым текстом
в подписи или сообщении. Проверка авторизации и финансовые операции прежние.
Mini App этой серией не изменяется.

Проверки: офлайн-тесты переходов текст → фото → подпись → другой баннер,
повторное использование file_id, замена изображения главного меню,
лимиты HTML/Unicode, сохранение длинного текста, ошибки редактирования,
сохранение предыдущего сообщения при неудачной отправке, соответствие файлов
ограничениям Telegram. Прямые вызовы рабочего Telegram API не выполнялись.

Обновление VPS:

```bash
cd /opt/session-shope
git pull --ff-only origin main
systemctl restart session-shope.service
```

Затем `/start` или `/menu` в боте; администратор также может открыть `/admin`.
