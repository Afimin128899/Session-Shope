# Объём и материалы SBAND

Поверх текущего оформления витрины и веб-админки подключён один общий
`miniapp/static/depth.css`. Существующие стили, логотипы и изображения сохраняются.

Изменения касаются отрисовки: многослойные контактные и мягкие тени, внутреннее
затемнение по краям, тонкие блики, полуматовая фактура карточек, лёгкий глянец
кнопок, глубина полей ввода и окон. Логотип получает тень по своему исходному
контуру. Существующий градиент главного блока не заменяется.

CSS не задаёт новую геометрию, отступы, размеры, шрифты, радиусы, базовые цвета
или трансформации. Нет новых объектов, надписей, 3D-наклона или фоновой анимации.
На телефоне тени легче; при запросе повышенного контраста фактура упрощается.
Новые сетевые зависимости и изображения не используются. Исходный логотип
остаётся исходного разрешения: апскейл до 8K или новая 3D-модель не заявляются.

Проверка: `node tests/sband_depth_browser.cjs` использует изолированные данные.
Для 320/360/390/768/1440 px тест отключает/включает новый stylesheet и сравнивает
позиции, размеры, тексты, шрифты, базовые цвета, рамки и радиусы исходных элементов
витрины и админки. Также проверяются все 28 административных действий, отсутствие
ошибок JavaScript и горизонтального переполнения. Скриншоты сохраняются в
/workspace/session-shope-previews/sband-depth-*.png.

Для отключения достаточно убрать подключение depth.css из двух HTML-шаблонов.
Серверные операции, оплата, доступ и Telegram-клавиатуры не затрагиваются.
