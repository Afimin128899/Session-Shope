# Режимы магазина, проверка товаров и язык · 5.7.0

## На проверке

Проблемный непроданный аккаунт можно скрыть до решения администратора:

- Бот: **Админ-панель → Аккаунты → карточка → Отправить на проверку**.
- Mini App: **Управление → Товары → На проверку**.

Нужна причина из 3–500 символов и подтверждение. Статус `review` исключает
товар из каталога, покупки, резерва и гарантийной замены. Существующие резерв
и запись в корзине отменяются в той же транзакции. Деньги не списываются.
В избранном ранее сохранённая карточка может остаться с отметкой недоступности.

Причина, администратор и время доступны только в управлении. Для возврата
используется отдельное действие **Вернуть в продажу**, также с причиной.
Оба решения сохраняются в журнале; причина предыдущей проверки не теряется.
Проданный, возвращённый или заменённый аккаунт так вернуть в продажу нельзя.

В Mini App есть фильтр **На проверке**; в боте — одноимённый раздел админки.
Пока товар скрыт, его характеристики можно исправить через форму Mini App.
Возврат делает товар доступным только в активной категории и ставит проверку
@SpamBot в очередь. Проверка спамблока и ручной статус — разные механизмы.
Поздний результат старой фоновой проверки не перезаписывает новое решение.

## Остановка продаж и технические работы

Бот: **Админ-панель → Режимы магазина**. Mini App: **Управление → Настройки → Изменить**.

**Продажи приостановлены** (`sales_paused=1`) блокирует новые покупки и резервы.
Каталог, избранное, баланс, пополнения, купленные аккаунты, коды, обращения,
гарантийная поддержка и возвраты продолжают работать. Ограничение действует
и для реальных покупок администратора; учебный магазин от него независим.

Блокировка проверяется в транзакции каждого пути покупки: бот, Mini App,
корзина и старые функции покупки. Проверка использует общую блокировку строки
настройки, изменение режима — исключительную. После подтверждения остановки
ожидающая покупка не сможет списать деньги по старой кнопке.

**Полные технические работы** (`maintenance_mode=1`) закрывают интерфейс
покупателей, сохраняя доступ администраторам. В боте есть отдельный баннер 🛠,
эмодзи, причина, ориентир завершения, проверка статуса, выбор языка и ссылка
на поддержку, если настроен её Telegram username. Mini App показывает отдельный
экран статуса. После завершения кнопка проверки снова открывает магазин.

Настраиваются `maintenance_reason`, `maintenance_eta`, `sales_pause_reason`.
Текст до 200 символов отображается как текст, без исполнения HTML. Ориентир
завершения не запускает автоматическое открытие. Если включены оба режима,
после выключения полных техработ продажи остаются остановленными.

Обработка уже подтверждённых оплат и возвратов Stars, сверка платежей
и фоновые финансовые задачи не зависят от этих переключателей.

## Русский и английский

Бот: **Мой профиль → Язык / Language** или `/language`.
Mini App: **Профиль → Русский / English**.

Выбор сохраняется в `users.language` для Telegram ID и общий для обоих
интерфейсов. Старые пользователи получают русский язык по умолчанию.
В боте изменение применяется к следующим экранам; Mini App обновляет выбор
при очередной синхронизации, обычно до 15 секунд, либо после открытия приложения.
Открытые формы бота сбрасываются при подтверждении изменения языка.

Переведены меню, каталог, профиль, корзина, покупки, оплата, бонусы, поддержка,
админские формы и технические сообщения. Каталог переводов общий для Python
и браузера: `miniapp/static/translations.json`. Динамические значения вставляются
после перевода шаблона: названия товаров, отзывы, переписка, причины решений,
заданные администратором объявления, пароли и коды не переводятся.

Для английских экранов бота используется нейтральный фирменный логотип без
русских заголовков; подпись и кнопки английские. Русские экраны сохраняют
баннеры разделов. Числа в Mini App форматируются по выбранному языку; валюта
магазина и курс Stars **1 ⭐ = 1,20 ₽** не меняются.

Уведомления поддержки, возвратов Mini App, пополнений, поступлений и снижения
цены определяют язык получателя. Ошибка чтения настройки не мешает отправке
платёжного уведомления: используется русский. Учебные названия товаров и
операторские тексты остаются исходными данными.

## Обновление и проверки

Миграции добавляют поля проверки в `accounts`, поле языка в `users` и настройки
режимов. Они выполняются при запуске и сохраняют существующие данные.
Новых внешних сервисов или ключей не требуется.

```bash
cd /opt/session-shope &&
git pull --ff-only origin main &&
systemctl restart session-shope.service
```

После обновления отправьте `/start` и заново откройте Mini App.

Если Git по-прежнему сообщает об изменённом `assets/welcome.png`, сохраните
только эту картинку перед повторным обновлением:

```bash
git stash push -m "welcome-before-update" -- assets/welcome.png
```

Проверки включают модульные сценарии транзакций и локализации, отдельную
MariaDB с одновременными покупкой/проверкой и остановкой продаж, сохранение
языка после повторного запуска, а также Chromium на 390/320 px. Интеграционные
проверки используют только одноразовую базу localhost и тестовые Telegram-подписи.
Рабочие Telegram-аккаунты, платежи и VPS при проверках не используются.
