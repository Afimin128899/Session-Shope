# Поделиться Mini App

В профиле, шапке и на главной есть «Поделиться Mini App». Окно показывает ссылку и кнопки копирования/отправки в Telegram. Если браузер запретил буфер обмена, поле выделяется для ручного копирования; сообщение об успешном копировании в этом случае не показывается.

Ссылка `https://t.me/ИМЯ_БОТА?start=miniapp` открывает бота, который выдаёт кнопку WebApp на настроенный HTTPS-домен MINIAPP_URL. Это работает без настройки отдельного short_name Mini App в BotFather. Каждый посетитель проходит собственную проверку Telegram initData; ссылка не содержит данные отправителя, query_id, hash или параметры страницы.

Если имя бота неизвестно, копируется только origin сайта. На странице входа доступна кнопка перехода в Telegram, когда имя бота определено. Публичный /api/app-info возвращает только bot_username. Переменные среды, токены, balance и данные пользователей не публикуются.

Проверки: `node tests/sharing.cjs`, `node tests/design_browser.cjs`, Python unittest. Реальные сообщения и платежи во время тестов не отправляются.
