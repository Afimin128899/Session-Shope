# Пополнение баланса

Поддерживаются xRocket Pay, Crypto Pay, Laveshka (Lava Pay), Platega · СБП и Telegram Stars. В боте откройте «Баланс → Пополнить», в Mini App — кнопку пополнения. Внешние сервисы появляются после настройки соответствующего ключа на VPS. Исключение — «СБП · Рубли»: по умолчанию доступна кликабельная заглушка без ключей, с переключателем в админских настройках. [Как включить рабочую оплату](SBP-PLACEHOLDER.md).

## Настройка на VPS

В существующей серверной `.env` задайте ключи без отправки их в чат:

```dotenv
XROCKET_API_KEY=ваш_ключ
XROCKET_API_MODE=exchange
CRYPTO_PAY_TOKEN=ваш_ключ
LAVE_PAY_API_KEY=ваш_ключ
PLATEGA_MERCHANT_ID=ваш_merchant_id
PLATEGA_SECRET=ваш_secret
```

`exchange` сохраняет контракт новой xRocket Exchange Pay API (Bearer, `/api/v1`). Если ваш токен выпущен для старого Rocket Pay API, укажите `XROCKET_API_MODE=tg` (Rocket-Pay-Key, `/tg-invoices`). Автоматического переключения после создания счёта нет: оно могло бы создать два счёта. Доступные источники контрактов и ограничения сверки документации перечислены в [PROVIDER-API-SOURCES.md](PROVIDER-API-SOURCES.md).

Laveshka использует `https://api.laveshka.io/merchant/v1`. Это сервис по адресу laveshka.io, отдельный от других сервисов с похожим названием Lava. Для xRocket и Laveshka сумма RUB конвертируется в USDT/USD, Crypto Pay выставляет fiat-счёт RUB. Проверка сервисом номера, владельца, суммы и оплаченного состояния предшествует зачислению. Первый бонус 10% сохраняется для этих способов и Platega.

СБП через Platega: от 1 до 10 000 ₽. Этот рублёвый предел относится только к СБП. Crypto Pay, xRocket и Laveshka: от 10 до 1 000 000 ₽, с учётом ограничений выбранного провайдера. Старые уже оплаченные счета обрабатываются с их настоящими суммами. Настройка Platega, формат Telegram ID из PDF-памятки, ограничения товаров и публичные документы: [PLATEGA.md](PLATEGA.md).

## Telegram Stars

Дополнительный платёжный ключ не нужен: используется токен самого Telegram-бота. Курс фиксирован: **1 ⭐ = 1,20 ₽**, например 100 ⭐ = 120 ₽. Принимается целое количество от 1 до 10 000 ⭐ (12 000 ₽). На Stars не начисляется дополнительный бонус 10%; право на первый бонус при внешнем пополнении сохраняется.

Счёт создаётся в валюте `XTR` с одним целочисленным `LabeledPrice` и пустым provider token. До оплаты проверяются владелец, сумма и срок счёта. Баланс меняется только по `successful_payment` или соответствующей операции из серверной истории Stars, а не по браузерному callback. Повтор одного charge ID ничего не зачисляет. Два разных действительно оплаченных charge ID учитываются отдельно.

Возврат Stars учитывается ровно один раз. Если средства уже потрачены, баланс может стать отрицательным до следующего пополнения. Возврат, пришедший раньше уведомления об оплате, сохраняется и не позволяет восстановить возвращённые средства поздним уведомлением. Вопросы оплаты: `/paysupport`.

Сервисные события оплаты проходят во время техработ, ожидания ввода, проверки подписки и антифлуда. Входящие обновления сохраняются при старте. Квитанции до записи в MySQL помещаются в приватную директорию `data/star-receipts` (переопределяется `STARS_RECEIPTS_DIR`). Не удаляйте её при обновлении. При сбое записи остаются для повтора; дополнительно фоновая сверка истории Stars восстанавливает пропущенные события. История обрабатывается порциями с сохранением позиции. Фоновая обработка работает вместе с основным `bot.py`.

## Обновление

```sh
cd /opt/session-shope
.venv/bin/python -m pip install -r requirements.txt
sudo systemctl restart session-shope.service
```

Перед этим получите изменения через `git pull --ff-only origin main`. Требуется aiogram 3.26 или новее. При запуске автоматически добавляются поле количества Stars в `payment_invoices` и таблица `star_payments`; она включена в проверку восстановления резервных копий. После обновления отправьте `/start` и заново откройте Mini App.

Проверки выполняются на тестовых ответах API и одноразовой БД; реальные оплаченные счета и рабочие ключи в облачной среде не использовались. При подключении внешних провайдеров проверьте выбранный режим API и доступ VPS к их адресам. Нативная оплата цифровых товаров Telegram использует Stars: https://core.telegram.org/bots/payments-stars.

Реферальные награды за подтверждённые пополнения, суточный лимит и блокировки ID: [REFERRALS.md](REFERRALS.md).
