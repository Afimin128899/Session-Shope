# Обновление интерфейса Mini App

Изменения относятся к текущим storefront_v2 и admin_static. Общие цвета, состояния
кнопок, ошибки полей, индикатор вкладок и анимации находятся в
`miniapp/static/ui.css` и `miniapp/static/ui.js`. Производственные зависимости
не добавлялись. API, права доступа, изображения, база и платёжные обработчики
сохранены.

Основные действия оформлены белыми кнопками, второстепенные — графитовыми,
удаление — приглушённым красным. Нажатие scale(0.97), появление 220 мс,
закрытие панелей 150 мс. Настройка reduced motion отключает движение. На телефоне
диалоги открываются снизу; на компьютере у админки боковая навигация и строки
товаров с колонками. Поиск, флаги, баланс, профиль и переписка используют общее
оформление. Экранная клавиатура учитывается через VisualViewport там, где
Telegram WebView его предоставляет.

Кнопки показывают запрос и блокируют повторное нажатие. Ошибки отображаются
рядом с полями, каталог можно загрузить повторно. Фоновое обновление остатка
ожидает закрытия редактора. Выделение товаров сохраняется между страницами;
индикатор массовой операции отражает фактические завершённые запросы. Удаление
показывает количество выбранных товаров и требует подтверждения. Служебные
операции с сессиями собраны в раскрывающемся меню.

Проверки:

```bash
python -m unittest discover -s tests -p 'test_*.py'
NODE_PATH=/path/to/node_modules SBAND_UI_ARTIFACTS=/tmp/sband-ui node tests/ui_polish_browser.cjs
```

Для браузерной проверки нужны Playwright и Chromium (`CHROMIUM_PATH`, по умолчанию
`/usr/bin/chromium`). Она работает с фиктивными API через перехват запросов;
не отправляет платежи, не использует реальные Telegram-сессии и ничего не удаляет
из производственной базы. Проверяет 320/390/768/1440 px, покупку и код входа,
ошибки оплаты/промокода, чат, массовые действия, формы, анимации и reduced motion.
Реальный Telegram WebView на телефоне и реальные платежи этой проверкой не охвачены.

Для применения обновите код и перезапустите текущий сервис. Если Mini App запущен
отдельным процессом, перезапустите его тоже. Закройте и заново откройте Mini App;
версии URL статики обновлены для сброса кэша.
