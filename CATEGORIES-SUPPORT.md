# Категории и сообщения (5.16.0)

В боте «Купить аккаунт» показывает Telegram-категории, а «Все категории» — только новые направления (Почта, Gmail, ChatGPT и другие), без стран.

Разделы Почта, Gmail, ChatGPT, Roblox, Discord, Steam, Spotify и YouTube изначально находятся в разработке. Включение: админка → Категории → нужный раздел → Вкл/Выкл (в Mini App: Изменить → Активна → Сохранить). Повторный запуск не сбрасывает выбор администратора. Включённый раздел показывает остаток («0 товаров», «1 товар» и т. д.), выключенный — «В разработке». Переключатель открывает раздел; товарные остатки и выдачу для новых типов нужно наполнять отдельно. Пока товаров нет, цена и кнопка оплаты не выдумываются.

Вкладка Mini App «Сообщения» предназначена только для поддержки, без личных сообщений между покупателями. Можно написать общий вопрос или продолжить обращение по заказу. Ответы видны в Mini App и в боте; администратор отвечает через существующую очередь поддержки. Общий вопрос не требует покупки. На пользователя создаётся один общий диалог, включая одновременные запросы; обращения по заказам сохраняют привязку к покупке.

Миграция разрешает NULL в support_tickets.purchase_id для общих вопросов; старые ID и внешние ключи сохраняются. Собственные обращения можно читать и продолжать, чужие недоступны; входящие сообщения ограничены 500 символами. Ответы обновляются каждые 15 секунд, если нет черновика; при просмотре старых страниц автоматического перехода к последнему сообщению нет. Скриншоты из старых обращений можно открыть в боте.

Проверки: unit tests, tests/design_browser.cjs, tests/integration_auto_categories.py на временной MariaDB. Внешние платежи и рабочие Telegram-сессии не используются.
