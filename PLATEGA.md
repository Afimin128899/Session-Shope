# Platega · СБП и правила магазина (5.9.0)

В Platega используется СБП (метод 2), сумма в RUB. Это дополнительный способ: остальные настроенные платёжные системы продолжают работать. Без Merchant ID и Secret способ не появляется у покупателей.

## Включение на существующем VPS

Получите Merchant ID и Secret в кабинете Platega. Вводите их только на VPS, не присылайте в чат и не публикуйте в GitHub.

```sh
cd /opt/session-shope
git pull --ff-only origin main
nano .env
```

Добавьте или измените две строки, сохранив остальные настройки:

```dotenv
PLATEGA_MERCHANT_ID=ваш_merchant_id
PLATEGA_SECRET=ваш_secret
```

После успешного обновления файлов и сохранения настроек:

```sh
systemctl restart session-shope.service
systemctl is-active session-shope.service
curl --fail --max-time 15 https://sbandsub.space/api/health
```

Ожидаемая версия — `5.9.0`. Заново откройте меню бота и Mini App. Способ оплаты: «Platega · СБП». Обновление исходников не выполняется автоматически на VPS из облачного рабочего места.

Если Git сообщает только о локальном изменении `assets/welcome.png`, сохраните именно эту картинку перед повтором pull:

```sh
git stash push -m "welcome-before-platega-update" -- assets/welcome.png
git pull --ff-only origin main
```

Не сбрасывайте локальные изменения других файлов и не заменяйте серверную `.env`. Перезапускайте сервис после успешного pull.

## Идентификатор покупателя

Настоящая почта не запрашивается. По странице 1 загруженной владельцем «памятки почты.pdf» передаётся:

```json
{"metadata":{"user_email":"463239844@telegram.org"}}
```

Число берётся из проверенного Telegram `from.id` / подписанного Telegram Mini App `initData`. Это постоянный идентификатор одного покупателя, а не настоящий почтовый адрес. Username, номер заказа, введённая клиентом почта и подставленный в JSON `user_id` его не меняют. Telegram ID остаётся персональным идентификатором; преобразование не делает его анонимным.

В API-примере на странице 2 памятки показан `@t.me`, тогда как текстовое правило на странице 1 указывает `@telegram.org`. Реализация следует текстовому правилу. Это описание фактически используемого формата, а не подтверждение согласования кассы банком.

## Создание и подтверждение

- POST `https://app.platega.io/transaction/process`; ключи только в серверных `X-MerchantId` / `X-Secret`.
- Метод 2, `paymentDetails.amount` в RUB, уникальный номер транзакции провайдера; payload связывает счёт с владельцем и рублёвой суммой.
- Redirect должен быть HTTPS. Возврат на сайт не подтверждает оплату.
- Автоматическая проверка через авторизованный GET `/transaction/{id}` и запасная кнопка «Проверить оплату».
- Зачисление только при `CONFIRMED`, совпавших UUID, payload, владельце, сумме и валюте; Merchant ID дополнительно сверяется, если присутствует в ответе.
- Уникальный маркер транзакции, изменение баланса и журнал оплаты сохраняются атомарно. Параллельные проверки не начисляют повторный платёж. Логи не содержат ключей, metadata или полных ответов провайдера.
- POST создания не повторяется автоматически; HTTP-редиректы с ключами запрещены. Если счёт появился у провайдера, но приложение сообщило об ошибке, сначала проверьте кабинет и поддержку.
- Существующий первый бонус 10% применяется к подтверждённому внешнему пополнению, включая Platega. Внутренние бонусы не являются дополнительным платежом покупателя. Комиссия 14% из предложения менеджера не добавляется покупателю кодом магазина.

Контракт транспорта и статуса сверялся с опубликованным сторонним пакетом `platega==0.1.5` и загруженной PDF-памяткой. В SDK `paymentMethod` находится в корне, в примере памятки — внутри `paymentDetails`: отправляется одно и то же значение 2 в обеих позициях. Официальная документация была недоступна из этой облачной среды. Реальная оплата с рабочими ключами не выполнялась; после включения проверьте один небольшой счёт и его однократное зачисление.

## Ограничения

Новые пополнения любым способом — максимум 10 000 ₽ за операцию. Внешние сервисы: минимум 10 ₽. Telegram Stars: от 1 до 8 333 целых звёзд; курс 1 ⭐ = 1,20 ₽, максимум 9 999,60 ₽. 8 334 звезды уже превышают лимит. Проверяется создание счёта и Stars pre-checkout, а не только поле браузера.

Цена каждого нового/редактируемого товара и итог одной покупки корзины — не более 10 000 ₽. Предел корзины проверяется после скидок и до списания, выдачи, расходования промокода или удаления корзины. Административная рублёвая корректировка и сумма балансового промокода также ограничены 10 000 ₽. Баланс может накапливаться из нескольких операций; он не обрезается. Ранее оплаченные счета и возвраты сохраняют настоящие суммы, включая старые счета на 10 000 Stars; старые неоплаченные Stars-счета сверх нового предела отклоняются перед оплатой.

Аккаунты РФ и Украины запрещены по категории/её названию и по фактическому номеру, подтверждённому импортом сессии. Проверки применяются при обычном добавлении, импорте ZIP (включая публикацию старого черновика), редактировании категории, покупке и выдаче замены. Категория «США» не скрывает номер +7 РФ или +380. Казахстан +76/+77 разрешён. Прямой доступ к базе данных не является пользовательским интерфейсом; административный SQL может обходить проверки добавления, однако покупка повторно проверяет фактическую запись под блокировкой.

При запуске миграция отключает запрещённые категории и переводит ранее непроданные неподходящие товары в «На проверке», удаляя их резервы и строки корзины. Сессии и старые заказы сохраняются, цены автоматически не уменьшаются. Вернуть запрещённый аккаунт в продажу кнопкой «Проверено» нельзя. Для дорогого разрешённого товара сначала установите допустимую цену, затем явно верните его в продажу.

## Документы и проверка банка

Ссылки владельца размещены отдельными кнопками только внутри раздела «Информация» бота. В главном меню сохранена отдельная кнопка поддержки. На экранах подписки и техработ доступен вход в «Информацию», без отдельных кнопок документов. В подвале Mini App оставлена одна ссылка «Информация» на публичную страницу `/about`:

- [Политика конфиденциальности](https://telegra.ph/POLITIKA-KONFIDENCIALNOSTI-SBAND-ACCS-11-05-2)
- [Пользовательское соглашение](https://telegra.ph/POLZOVATELSKOE-SOGLASHENIE-SBAND-ACCS-11-05)
- [Цены и поддержка](https://sbandsub.space/about) — публичная страница без авторизации, с актуальными базовыми ценами доступных категорий и способом обращения по заказу. Прямой контакт берётся из существующего `support_username` / `SUPPORT_USERNAME`.

`mekbuda` показано в информации бота, подвале Mini App и на `/about`. После регистрации кассы его можно убрать из `utils/legal.py`, `utils/constants.py` и `miniapp/static/index.html`. Страница `/about` должна проксироваться Caddy на тот же Mini App; отдельного сервиса не требуется.

Контент опубликованных владельцем страниц Telegra.ph не был проверен: исходные страницы недоступны из среды. Проверку действительных реквизитов/контактов в этих документах выполняет владелец. Публикации Telegram-канала этим обновлением не изменяются.

## Проверки разработки

```sh
python -m unittest discover -s tests
python tests/integration_platega_policy.py
python tests/integration_shop_control.py
```

Интеграционные проверки используют отдельную одноразовую MariaDB на `127.0.0.1:13307`, не `.env` проекта. Провайдер отвечает тестовыми данными; ни один реальный платёж не создаётся. Для мобильного Chromium: первый интеграционный скрипт с `--serve`, затем `node tests/platega_policy_browser.cjs`.
