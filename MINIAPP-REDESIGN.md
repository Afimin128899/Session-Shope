# Mini App SBAND · 5.19.0

Обновление текущего Mini App с общей базой Telegram-бота. По выбранному владельцем варианту сохранены Python/aiohttp и MySQL/MariaDB. Переноса на PostgreSQL, отдельной регистрации по почте и нового сайта нет. Первый вход и идентификация выполняются через подписанные Telegram initData; право администратора определяется сервером. Доступ к покупкам и операциям ограничен владельцем.

Интерфейс: фон #101010, поверхности #191919, белые кнопки, круглые переключатели и нижние вкладки «Маркет / Профиль». Поддерживаются мобильные и широкие экраны, клавиатура и настройка уменьшения движения. Название проекта — SBAND, тексты и логотип Liberty не используются.

В маркете доступны товары с настоящей ценой в рублях, флагом и статусами, поиск, выбор страны и сортировка. «Популярное» считается по реальным невозвращённым покупкам. Корзина сохраняет существующий резерв; списание, промокод и выдача заказа проходят общей транзакцией на сервере. Номер и пароль выдаются только владельцу покупки, строки Telegram-сессий браузеру не передаются.

Профиль содержит сводку по рублям, покупки, историю операций и пополнений, реферальную программу, промокоды, бонусы и поддержку. Пополнения показаны без бонусов, расходы — без возвращённых заказов. Старые заказы без суммы не оцениваются по текущей цене. История показывает сохранённые источники; дополнительный первый бонус внешних пополнений может не иметь отдельной строки.

Пополнение поддерживает Crypto Pay, Heleket, СБП через Platega, Telegram Stars и ранее подключённые xRocket/Lava Pay. Сервисы без ключей скрыты; управляемая заглушка СБП сохраняется. Проверка кнопкой и фоновый опрос работают через сервер. Stars открываются нативным окном Telegram, курс 1 ⭐ = 1,20 ₽. Подробности и ключи: [PAYMENTS.md](PAYMENTS.md).

Админка сохраняет управление товарами, загрузкой, ценами, покупателями, балансами, категориями и промокодами. В новом разделе «Платежи» доступны фильтр статуса, поиск и повторная проверка. Проверка не позволяет вручную объявить неоплаченный счёт оплаченным. Результат записывается в админский журнал.

## Обновление существующего VPS

```bash
cd /opt/session-shope &&
git pull --ff-only origin main &&
systemctl restart session-shope.service
```

Новых зависимостей или переноса базы для этого выпуска нет. Дополнительные переменные нужны только для Heleket. После перезапуска закройте Mini App и откройте снова. Проверка сервиса:

```bash
systemctl is-active session-shope.service
curl --fail http://127.0.0.1:8080/api/health
```

Для чистого VPS остаётся [install-fresh.sh](install-fresh.sh); порядок установки домена и HTTPS описан в [MINIAPP.md](MINIAPP.md). Не заменяйте существующий файл окружения примером и не сбрасывайте базу при обновлении.

## Проверки

- `python -m unittest discover -s tests -p 'test_*.py'` в подготовленном виртуальном окружении.
- `node tests/design_browser.cjs` и `node tests/stars_browser.cjs` с Playwright/Chromium. Все платёжные ответы синтетические, реальные средства не списываются.
- `python tests/integration_auto_categories.py` на одноразовой MariaDB: владельцы, финансовая сводка, история, фильтры, покупки, однократное зачисление и права администратора. Скрипт использует отдельную тестовую базу на localhost:13307; не направляйте его на рабочую БД.

Ключи провайдеров не использовались при разработке. Реальная доступность мерчанта, его комиссии и выдача счёта проверяются на VPS после настройки кассы; адаптер Heleket сверялся с официальным опубликованным SDK.
