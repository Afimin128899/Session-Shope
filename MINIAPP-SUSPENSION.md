# Отключение Mini App и прямая поддержка

Пользовательский Mini App временно отключён. Его исходники, изображения,
`MINIAPP_URL`, адрес прослушивания и порт сохранены. При запуске бот заменяет
сохранённую кнопку Web App обычным меню команд; кнопки запуска и ссылки `/start`
больше не открывают приложение. Старые прямые ссылки и API возвращают сообщение
об отключении. Публичная информация `/about` и проверка `/api/health` сохранены.

Отдельное администраторское приложение находится в `miniapp/admin_static/`,
точка входа — `/admin-app`. Сейчас оно также отключено: страница, файлы и API
администратора возвращают 404, кнопок запуска нет. После отдельного разрешения
владельца приложение можно включить независимо от пользовательского. Данные
доступны только после серверной проверки подписи Telegram и `ADMIN_IDS`.
Флаги выпуска в `utils/app_access.py` по умолчанию равны `False`; кнопок и команд
для самостоятельного включения нет. Тестовые приложения включают флаги только
в изолированных фикстурах.

В отдельном приложении подготовлены обзор, товары и редактирование цены,
поиск пользователя и управление балансом, заказы, категории, промокоды и
просмотр платежей. Используются прежние серверные операции с проверками прав
и журналом действий. Платёжные интеграции и настройки не изменены.

## Поддержка

Любой пользователь может открыть «Поддержка» или отправить `/support`,
в том числе без покупок, без подписки на канал и во время техработ.
После этого текст и вложения передаются администраторам из `ADMIN_IDS`.
Кнопка «Ответить пользователю» у полученного сообщения открывает ввод ответа;
он доставляется пользователю в тот же бот. Целевой ID хранится в кнопке, поэтому
повторно открыть ввод ответа можно и после перезапуска бота. Сам незавершённый
ввод, как и другие формы текущего бота, хранится в памяти до перезапуска.
Для выхода предусмотрены кнопка завершения переписки и `/cancel`.

Бот подтверждает передачу, только если сообщение удалось скопировать хотя бы
одному администратору. Ошибки доставки не выдаются за успешную отправку.
У пользователя нет номера обращения, статуса или списка тикетов.
Гарантийные сообщения используют прямую переписку с прежней проверкой
принадлежности покупки и срока гарантии при отправке.

Старый роутер тикетов не подключён, старые кнопки направляют в прямую поддержку.
Прежние таблицы и код сохранены для истории заказов и возвратов; новые тикеты
не создаются. HTTP-маршруты тикетов остаются закрытыми и при тестовом включении
приложений.

## Проверка и обновление

Автотесты: `python -m unittest discover -s tests -p 'test_*.py'`.
Тесты не используют рабочие платёжные ключи или рабочую базу.

На сервере обновление применяется обычным способом:

```bash
cd /opt/session-shope &&
git pull --ff-only origin main &&
systemctl restart session-shope.service &&
systemctl is-active session-shope.service
```

База не мигрируется для этих изменений; изображения и сохранённые настройки
не заменяются. Оба Mini App должны оставаться отключёнными до отдельной команды.
