# Помощник и рекламные ссылки

Добавлена ровно одна новая роль: **Помощник**. Существующие администраторы из
`ADMIN_IDS` сохраняют свои права. Пользователи по умолчанию помощниками не являются.

## Назначение

Пользователь должен сначала открыть бота. Администратор назначает роль:

```text
/helper 123456789 on
```

Снять роль:

```text
/helper 123456789 off
```

В админке бота кнопка «Помощник» показывает текущих помощников и команды.
В Mini App администратору доступен раздел «Помощник» с назначением по Telegram ID
и снятием роли с подтверждением ID. Роль хранится в базе и переживает перезапуск.
Администратору нельзя одновременно назначить роль помощника.

## Кабинет помощника

Помощник открывает `/admin`: там есть «Реклама» и вход в его кабинет Mini App.
В админском Mini App помощнику показывается только раздел **«Реклама»**.
Администраторы и обычные пользователи этой кнопки не видят. Проверка прав
выполняется сервером при каждом запросе, а не только скрывает кнопки.

В разделе помощник:

- Создаёт рекламную ссылку с названием до 80 символов.
- Копирует ссылку вида `https://t.me/BOT_USERNAME?start=ad_TOKEN`.
- Видит число новых регистраций по каждой своей ссылке.
- Открывает список пользователей: Telegram ID, текущий username (если есть),
  время регистрации. В интерфейсе время показывается по Москве.

Максимум — 100 ссылок на помощника. Списки пользователей выводятся постранично.
Посторонняя ссылка возвращает «не найдена»; нельзя подставить чужой owner_id,
прочитать чужие рекламные списки, обычных рефералов, платежи или балансы.

## Как считается результат

Это учёт **новых регистраций после /start**, не кликов по URL. Уже зарегистрированные
пользователи не добавляются задним числом. Повторные входы и переходы по другим
ссылкам не увеличивают счётчик и не заменяют источник. Источник записывается в той
же транзакции, что и новый пользователь; откат регистрации отменяет запись.

Параметр сохраняется в состоянии бота на время обязательной подписки и применяется
при её подтверждении. Ссылки с `ad_` независимы от обычных ссылок `ref_`: рекламная
регистрация не создаёт личного реферала и не начисляет реферальную награду.
Обычный приветственный бонус магазина сохраняется по действующим правилам.

Снятие роли закрывает кабинет и создание ссылок, включая старые открытые страницы.
Старые ссылки перестают учитывать новых пользователей, пока владелец ссылки не
получит роль снова. Существующая статистика сохраняется. Назначение/снятие роли
и создание рекламной ссылки попадают в журнал администратора.

## Установка

При запуске бот автоматически добавляет `users.is_helper` (по умолчанию 0) и таблицы
`advertising_campaigns`, `advertising_users`. Миграция повторяемая, прежние
рефералы, деньги и покупки не меняются. Перед обновлением используйте обычную
резервную копию. После установки нужен перезапуск существующего сервиса.

Ветка до слияния PR: `codex/helper-advertising`. На рабочий VPS изменения из этой
среды автоматически не устанавливаются. Назначение конкретных людей выполняет
администратор после установки, роль никому автоматически не выдаётся.

## Проверки

```sh
PYTHONPATH=tests:. python -m unittest test_helper_advertising test_miniapp test_admin_web test_admin_tools test_storefront_v2 test_miniapp_upgrade test_referral_rewards test_welcome_bonus
node tests/helper_advertising_browser.cjs
node tests/ui_polish_browser.cjs
```

Интеграционный тест использует только отдельную локальную MariaDB на порту 13308,
создаёт случайную тестовую базу и удаляет её. Боевые настройки не читаются:

```sh
docker run -d --rm --name session-shope-advertising-test -e MARIADB_ALLOW_EMPTY_ROOT_PASSWORD=1 -p 127.0.0.1:13308:3306 mariadb:11.4
# Дождаться готовности: docker exec session-shope-advertising-test healthcheck.sh --connect --innodb_initialized
PYTHONPATH=tests:. python tests/integration_advertising.py
docker stop session-shope-advertising-test
```

Проверяются схема и повторная миграция, изоляция владельцев ссылок, отзыв роли,
постраничные списки, параллельная регистрация одного пользователя, откат транзакции
и отсутствие реферальных выплат. Браузерные тесты работают с фикстурами API.
