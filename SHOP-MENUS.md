# Меню покупки в боте

«Купить аккаунт» открывает «Авторег», «С отлегой» и «Премиум».
Внутри доступны самый дешёвый аккаунт, поиск страны, массовая покупка,
страны в две колонки, полный список стран и возврат назад. Для аккаунтов
с отлегой страна открывает выбор года регистрации в три колонки.

Данные берутся из существующих товаров. «Авторег» — основной ассортимент
без подтверждённого Premium; неизвестный год регистрации не выдумывается.
«С отлегой» использует подтверждённую дату регистрации не менее 30 дней назад.
«Премиум» использует сохранённый признак Premium. Это фильтры одной базы,
поэтому старый Premium-аккаунт также может находиться в разделе с отлегой.
Страны определяются по номеру; существующие ограничения продаж сохранены.
Внутри страны товары разделяются по сохранённому статусу спамблока:
например, «США Вечный СБ» открывает только аккаунты с вечным спамблоком.
Для ограниченных и непроверенных аккаунтов используются отдельные пометки.
Цены, остатки, годы и массовая покупка относятся к выбранной группе.
Показываются только активные, свободные товары без чужого действующего
резерва и без выполняющейся проверки спамблока. Цены учитывают прежнюю
реферальную скидку. Цены, страны, годы и количество со скриншотов не копируются.

Главное меню содержит пять пользовательских кнопок: «Купить аккаунт»,
«Пополнить баланс», «Мой профиль», «Техподдержка», «Все категории».
В профиле находятся покупки, пополнение, реферальная система, бонусы,
ввод промокода, правила и настройки. В настройках — информация и язык.
Пользовательские кнопки отзывов убраны, ранее сохранённые данные остаются.
Правила расширены рекомендациями по безопасному входу; сроки и условия
гарантии в конкретных заказах не изменены. В информации сохранены прежний
текст, документы и проверочное слово, подпись сокращена до «Код: …».
Абзац с лимитами оплаты убран только из текста информации, без изменения
способов пополнения, курсов или платёжных ограничений.
«Номер для смены» и «Бот рассылки» не добавлены. Оба Mini App остаются
отключёнными. Изображения, платёжные провайдеры и настройки не меняются.

Иконки новых меню загружаются из `tgmacicons` при запуске бота. Обычные
эмодзи и флаги из надписей удаляются при отображении, без изменения сохранённых
названий. Если набор временно недоступен, новые кнопки остаются без иконок;
замены из другого набора или обычных эмодзи не подставляются.

## Массовая покупка

Покупатель выбирает страну и от 1 до 20 аккаунтов. Подбор самых дешёвых
товаров и резерв на пять минут выполняются одной транзакцией без списания.
На подтверждении показываются количество, итоговая сумма и существующая
оптовая скидка. При выборе конкретного года он также отображается.

Оплата использует прежнюю общую операцию корзины. Все заказы и списание
проводятся одной транзакцией. Изменившиеся цена, оптовая скидка, гарантия,
спамблок, год или Premium требуют нового подтверждения; чужой или истёкший
резерв не оплачивается. Повторное нажатие не создаёт повторное списание.
Отмена освобождает только товары, добавленные этой операцией, сохраняя
ранее существовавшую корзину. После оплаты данные и кнопка получения кода
приходят по каждому заказу; история остаётся в «Моих покупках».

## Проверки

```bash
python -m unittest discover -s tests -p 'test_*.py'
python tests/integration_shop_navigation.py
```

Интеграционный тест требует отдельную MariaDB на `127.0.0.1:13307`, создаёт
случайную временную базу и удаляет её после проверки. Рабочая база и Telegram
не используются; конфигурация для теста подменяется до импорта приложения.
